Strike API Sync

Connect your Strike API key to automatically sync Lightning invoice receives and your live BTC balance. Note: The Strike API only exposes invoices you created (Lightning receives). BTC purchases, DCA orders, sales, and withdrawals are not available via the API — continue using CSV import for those.

{{if .StrikeAPIConnected}}
Connected · {{.StrikeAPIKey}}
{{else}}

Generate a read-only API key at dashboard.strike.me → API → Create Key. The partner.invoice.read scope is required.

{{end}}

Coinbase API Sync

Connect your Coinbase CDP API key to automatically sync your full BTC transaction history (buys, sells, sends, receives, and crypto-to-crypto trades) and live balance.

{{if .CoinbaseAPIConnected}}
Connected · {{.CoinbaseAPIKeyID}}
{{else}}

Create an API key at cdp.coinbase.com with Trade - View permission and Ed25519 algorithm. Enter the Key ID and the base64-encoded private key shown after creation.

{{end}}
